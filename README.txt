JOSHUA G. RAMOS — PORTFOLIO WEBSITE

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome or another browser.

HOW TO CUSTOMIZE
- Profile photo: replace assets/joshua-profile.png with your own photo (keep the same filename).
- Project images: replace the SVG files in assets/ with your own project screenshots. If you use JPG/PNG files, update the matching image src in index.html.
- Contact email: search index.html for your.email@example.com and replace it with your real email.
- Social links: add your own links in the contact section if needed.

IMPORTANT
The original reference website's project images could not be extracted here, so this starter includes custom illustrative previews. The descriptions are original drafts based on project names/context and should be checked against the actual features of your projects before publishing.
